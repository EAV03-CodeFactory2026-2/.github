## ¿Quiénes somos?

Somos el equipo **EAV03**, un grupo de estudiantes de Ingeniería de Sistemas de la Universidad de Antioquia que desarrollamos software real en el marco del módulo **Fábrica Escuela — CodeFactory 2026-2**.

Trabajamos con metodología **Scrum** en sprints de tres semanas, aplicando buenas prácticas de ingeniería: revisión de código por Pull Request, análisis estático con SonarCloud, pruebas unitarias con JUnit 5 y criterios de aceptación en Gherkin.

---

## 🏗️ Proyecto: Plataforma de Reservas de Servicios

Una API backend SaaS **multi-tenant** que permite a propietarios de negocios gestionar servicios, proveedores y reservas de clientes. Pensada para clínicas, consultorios, salones de belleza y cualquier negocio que opere con citas programadas.

### Módulos del Sprint 1
| Módulo | Descripción |
|--------|-------------|
| **Autenticación** | Login con JWT, protección de rutas, tokens stateless |
| **Negocios** | Registro y activación inmediata de negocios (multi-tenant) |
| **Catálogo de Servicios** | Gestión del catálogo de servicios por negocio |
| **Herramientas Dev** | Script de seeding para entornos de desarrollo |
